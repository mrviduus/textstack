# Ship a first pull request

You get: a pull request that passes the checks and is ready for review.

Time: about 30 minutes for a small change.

## Before you start

- The app runs on your machine: [Run TextStack locally](run-locally.md).
- You have a GitHub account.
- You read the [contributor agreement](../../.github/CONTRIBUTING.md#contributor-license-agreement).

## Two words

- A **pull request** (PR) is your change, offered to the project for review.
- **CI** is the set of checks GitHub runs on every pull request, by itself.

## The three lessons

1. [Pick the work](pr-1-pick-the-work.md): an issue, your own copy, a branch.
2. [Change and check](pr-2-change-and-check.md): the change, the checks, the commit.
3. [Open the pull request](pr-3-open-the-pull-request.md): push, describe, name the area.

This is [story 8](../stories/index.md): a contributor changes TextStack.
