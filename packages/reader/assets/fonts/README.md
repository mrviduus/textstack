# Literata

Default book font, with Latin and Cyrillic coverage. Full static WOFF2 faces (regular,
bold, italic, bold italic), unchanged from [googlefonts/literata](https://github.com/googlefonts/literata/tree/0c2761b727a1b3a7cffd313c37f0f5163dfc7a63/fonts/webfonts).

Pinned source commit: `0c2761b727a1b3a7cffd313c37f0f5163dfc7a63`.
License: SIL Open Font License 1.1, in `Literata-LICENSE.txt`; also embedded in the reader's font chunk.

The existing `serif` setting selects Literata, including previously saved serif choices.
Brand typography in the app remains TextStack (Michelangelus).
