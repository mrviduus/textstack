How a book moves through TextStack

One ASP.NET Core API, one worker, one Postgres, three clients and an MCP bridge for Claude. Queues are Postgres tables that workers poll; there is no broker. Everything runs on a home server behind a Cloudflare tunnel. Pick a scenario to trace it, or click a box marked ⤢ to zoom in.

    Why a tunnel

    What we gainWhat it costs
    No open inbound port and no public IP; works behind a home routerCloudflare is a single point of failure. Tunnel down means site down
    Free TLS certificates and DDoS protection at the edgeCloudflare ends TLS, so it sees all traffic
    The home IP stays hiddenEvery request reaches nginx from 127.0.0.1, so the real client IP only arrives as a header
